## 🌇 Score at **Dusk**

**Dusk** falls when every **Bun** has **escaped, been eaten, or been injured**.
Score each **Brace** separately, include any **Natural Roll** adjustments from
its **Chases**, and record the result for that day.

| Outcome | **Bun** player | **Dog** |
| --- | ---: | ---: |
| **Bun** escaped | **+2**, plus any repeat-escape bonus | 0 |
| **Bun** injured | **−(previous escapes + 1) × injury multiplier** | 0 |
| **Bun** eaten | **−1** | **+1** |
| Both **Buns** in the same **Brace** escaped that day | **+1 extra** | 0 |
| Both **Buns** in the same **Brace** were eaten that day | **−1 extra** | **+1 extra** |


A full **Brace** eaten scores **−3** for its player and **+3** for the **Dog**. The
**Dog** earns the same catch points whether a **Bun** is fresh or has escaped
before.

### 🐾 Repeat escapes

Each time a **Bun** escapes, add **+1 for each earlier day that same Bun
escaped**.

| Escape by the same **Bun** | Points |
| --- | ---: |
| First | **2** |
| Second | **3** |
| Third | **4** |

The daily **+1 Brace bonus** still applies. If the same two **Buns** escape
on all three days, they score **5 + 7 + 9 = 21 points**. A **Bun** that escaped
on Day 1 and was injured on Day 2 gets **3 points** if it escapes on Day 3.
It has only one earlier escape.

### 🧮 Daily **Brace** score matrix

Read each row in either order. The scores include the daily **Brace** bonus or
penalty. Add any **Natural Roll** adjustments separately. For each injured **Bun**,
use its actual penalty from **Eat or Injure**.

| One **Bun** | Other **Bun** | **Bun** player | **Dog** |
| --- | --- | ---: | ---: |
| Escaped | Escaped | **+5 to +9** | 0 |
| Escaped | Injured | **+2 to +4**, minus the injure penalty | 0 |
| Escaped | Eaten | **+1 to +3** | **+1** |
| Injured | Injured | **Subtract both injure penalties** | 0 |
| Injured | Eaten | **−1**, minus the injure penalty | **+1** |
| Eaten | Eaten | **−3** | **+3** |

For example, if a **Bun** with one previous escape gets away and its partner
is injured with a 2-point penalty, the **Bun** player scores **3 − 2 = 1** and
the **Dog** scores **0**.
