# Run Bun! — Nasty artwork generation and editing protocol

Read [shared artwork rules](../../../GEN.md), [Bun anatomy and style](../Bun/GEN.md), and [Dog design](../Dog/GEN.md). This guide does not authorize application code edits.

## Purpose

One Bun deliberately endangers another to improve their own escape from a Dog. The betrayal, victim, approaching threat, and betrayer's escape must be visually understandable. Preserve adorable youthful Bun family proportions even when the behavior is nasty. Victims evoke sympathy; betrayers can look sly, falsely reassuring, desperate, or selfish. Avoid ambiguous scenes that could instead read as helpful rescues.

Use full color, established detailed illustration, sharp foreground and background, distinct natural Bun fur and Victorian steampunk outfits. Each Bun hand has three fingers and one thumb with rounded fingernails. Dogs are huge, powerful, individually distinct demonic canines with two eyes and restrained sinister colors. Vary builds, coats, ears, muzzles, demonic traits, and direct visual references. Do not clone one Dog across the set.

Active pursuit requires urgent escape poses and frightened victims. Use airborne strides where appropriate. Stealth and deception may use quieter poses when the story requires them. Do not add graphic injury merely to make betrayal readable.

## Geometry and production

Follow shared physical-logic checks before generation and visual review afterward: coherent perspective, connected escape routes, hinges opposite latch edges, plausible rope tension and attachments, supported structures, aligned wheels and rails, hands contacting tools, and no intersecting bodies. Prefer a simple readable mechanism over decorative complexity.

Back up Carrot 2.png before replacing the prototype. Preserve every generated source and rejected revision under Resize. Install each completed card and immediately add its matching CSV row, Type Nasty, preserving all current columns and existing rows. Description and Flavor remain blank unless requested.

The requested first title is Free Carrot? (FREE, not Freak). The user specified Free Carrot-Q as the filename and CSV Name; the user will handle the displayed question mark in drawing.
