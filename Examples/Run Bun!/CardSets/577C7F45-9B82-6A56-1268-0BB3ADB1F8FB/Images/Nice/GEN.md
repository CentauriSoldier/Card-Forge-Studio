# Run Bun! — Nice artwork generation and editing protocol

Read [shared artwork rules](../../../GEN.md), [Bun design and anatomy](../Bun/GEN.md), and [Dog design](../Dog/GEN.md). This guide does not authorize application code edits.

## Purpose and style

Nice cards center on a Bun deliberately helping other Buns escape a Dog. Make the helper, beneficiary, helpful action, and resulting escape opportunity readable at card size. Show kindness, courage, ingenuity, shelter, distraction, rescue, or practical assistance. No betrayal in this set. The frightening Dog creates urgency, while the adorable Buns remain the emotional focus.

Use installed approved artwork directly as references. Full color, polished detailed illustration, sharp foreground and background, no motion blur or bokeh. Buns retain youthful family proportions and distinct natural fur/outfits; each hand has three fingers and one thumb with rounded fingernails, each foot four digits. Dogs are enormous powerful demonic canines, exactly two eyes, restrained sinister colors, and only slightly steampunk.

Vary settings, viewpoints, numbers of Buns, poses, help methods, and partial versus full Dog visibility. Running may use airborne strides; lifting, pulling, bracing, or supporting loads requires credible contact and balance. Every action must work physically. Follow the shared explicit door/hinge, wheel/axle, track, path, rope, and mechanism checks. Do not repeat the same rescue composition throughout the set.

## Dimensions and installation

The current Draw.lua Nice opening at base 825 × 1125 is approximately X 43, Y 183, width 736, height 494. Install landscape PNGs at 1472 × 988, aspect 368:247. Scale proportionally, never stretch. Keep key faces, hands, and action clear of frame corners and overlaps.

Use Images/Nice/Name.png and CSV Type Nice, one matching row per installed image. Leave Description and Flavor blank unless instructed. Follow shared backups, source/rejected-revision preservation, immediate CSV registration, and verification rules. File checks do not establish in-Studio appearance.
