Make the rules easy to follow.

Documents and order

Use the Content editor’s file controls to add, rename or delete a Markdown document. Use Document Order to arrange chapters with drag-and-drop or the arrow buttons. Renaming a file can affect links you wrote by hand; deleting a document removes its source.

Headings

One to six # characters introduce heading levels. Use a space after them. The toolbar provides all six levels.

## Getting started
Heading text and link IDs do different jobs

A heading is the name readers see. A section marker or explicit anchor gives links a stable destination. Do not copy the same ID into multiple places.

Everyday editing

The editing toolbar provides Undo, Redo, Cut, Copy, Paste, Select all and Find / Replace. Undo and Redo cover content typing and toolbar edits, including style wrapping, Markdown, table insertion and anchors.

CommandShortcut
UndoCtrl+Z
RedoCtrl+Y or Ctrl+Shift+Z
Cut / Copy / PasteCtrl+X / Ctrl+C / Ctrl+V
Select allCtrl+A
Find / ReplaceCtrl+F / Ctrl+H

Find searches literal text, with optional Match case. Next and Previous wrap through matches; Enter finds the next match and Shift+Enter finds the previous one. Replace changes the selected match; Replace all is one undoable edit. Escape closes the search panel.

Undo history belongs to the open content document and retains up to 200 states. Changing documents or closing the editor clears that history. Undoing back to the saved text restores the Saved status. If clipboard buttons are unavailable in your browser host, use the keyboard shortcuts in the editor.

Selection and preview

Select text, then use a Markdown or style button to wrap it. The existing selection-help control explains the editor’s multiple-selection tools. The preview updates after a short pause; Refresh preview requests it immediately.

Turn line numbers on or off under Options → Manual Editor, then choose Apply. This preference updates the open editor.

Manual Editor Guide / 04

One source for your text styles.

The manual uses the named styles defined by CFS. Create and edit them through Game → Style Editor.

Apply a style

  1. Choose an existing style.Find it in the manual’s style palette. Use the search field to narrow the list.
  2. Select your text.Click the style button. The editor normally inserts <Name>…</Name>. For a reserved name, it uses the colon escape to keep the style distinct from built-in formatting.
  3. Save the document.Styling the preview does not save your text automatically.
<MyStyle>This text uses the CFS style named MyStyle.</MyStyle>

MyStyle is an example name: it must exist in your game before export. Favorite style buttons reference the same named styles; they are not separate definitions.

Normal tags first; escape reserved names when needed

Write <Name>text</Name> for ordinary styles. The alternative <:Name>text</:Name> explicitly selects a CFS style when its name conflicts with a reserved tag.

SyntaxMeaning
<sup>2</sup>Built-in superscript
<:sup>2</:sup>The CFS style named sup
<:MyStyle>…</:MyStyle>An explicit CFS style reference
Use the colon on both ends

<:Name> closes with </:Name>. Normal tags are the default. Style buttons add the colon only for reserved names such as sup and G; you can also type the escaped form yourself.

Keep text styling and layout separate

A named style controls typography and text effects. A heading bar or page background is a manual appearance property. There is no separate web-only style editor to keep synchronized.

The Web renderer translates native styles into CSS. Some native effects cannot be reproduced exactly in a browser; export messages report supported approximation limits.

Manual Editor Guide / 06

Explain once. Make it easy to find.

Give recurring terms a consistent definition without repeating a paragraph every time.

Create an entry

  1. Open the Glossary tab.Choose New entry or select an existing entry.
  2. Write a name and definition.Definitions support Markdown, named styles and images. Use the entry preview to review them.
  3. Save the entry.Save alternatives separately when you add matching terms.

Keywords link automatically

Text wrapped in the Keyword or ManualKeyword style automatically links to a glossary entry when the complete text matches its name or an alternative name. You do not need to add a G tag around that styled keyword.

<ManualKeyword>Deploy</ManualKeyword>

For example, if Deployment has Deploy as an alternative name, this keyword links to Deployment’s definition. Use whichever keyword style is defined in your game; these example names are not created automatically for every game.

A match is required

Keyword formatting by itself does not create a definition. If no glossary name or alternative matches, the text keeps its style without gaining a glossary link. Ordinary untagged words are not automatically linked.

Use G for an explicit declaration

Select a term in the Content editor and use Glossary link. This wraps it in the special glossary tag:

<G>Deployment</G>

Use <G> when you want a glossary link without applying a keyword style, or want to explicitly mark a term as a glossary reference. The text must still match an entry name or one of its alternatives. A named CFS style called G is different: write <:G>…</:G> to select that style.

Alternative names: several terms, one definition

Alternatives let abbreviations, plural forms and other names point to the same entry. They do not create separate definitions, and they do not rename the entry.

  1. Select the glossary entry.For example, select an entry named Deployment.
  2. Add one alternative per line.Enter only the matching words—no style tags, quotes or comma-separated list.
  3. Choose Save alternatives.The alternatives have their own save action. Saving the definition does not replace that step.
  4. Use a keyword or G tag in your text.The reader resolves the whole tagged phrase to the original definition.
Deploy
Deploying
Deployments

All three alternatives above point to Deployment. These references therefore reach the same definition:

<ManualKeyword>Deploy</ManualKeyword>
<G>Deployments</G>
Matching ruleWhat it means
Case-insensitivedeploy, Deploy and DEPLOY match the same alternative.
Whole tagged text<G>Deploy a unit</G> does not match the alternative Deploy. Tag just the term, or add the complete phrase as an alternative if appropriate.
No automatic plural or abbreviation expansionAdd Deployments separately. For an entry named Command Point, you could add Command Points and CP.
One destination per nameDo not reuse an entry name or alternative for another definition. Ambiguous matches are rejected.

To remove an alternative, delete its line and choose Save alternatives. Check any references that relied on it; they will no longer link unless they match another name for that entry.

Hover delay

The global delay applies to every glossary popup. Set it in milliseconds; zero opens the popup immediately. Use Save delay to persist the change.

Definitions are content

Deleting an entry removes its definition and alternatives. Text that used it remains, but its glossary link will no longer resolve to that entry.

Manual Editor Guide / 08

From saved rules to a shareable manual.

Export the files you have saved, then inspect the result as a reader would.

Export a website

  1. Save your documents.Export reads saved source files. Unsaved editor text is not the exported source.
  2. Open Manual Export.Choose Web and start the export.
  3. Watch the log.Preflight checks sources and assets before building and packaging the website. Address any reported blocking issue.
  4. Review the result.Open Exports/Manual/Web/index.html in the active game folder. Share the complete Web folder, not just index.html.

What gets packaged?

The website includes reader assets, manual images, generated style CSS, appearance CSS and the font files selected by the Web exporter. Font redistribution permissions remain your responsibility.

In the reader, the small Auto-collapse checkbox controls whether expanding a contents group closes other groups.

Read a preflight message

MessageWhat to check
Undefined style tagCheck the name in Game → Style Editor. A prefix or spelling change must also be reflected in the document. Use <:Name> for an explicit style.
Missing image or local assetCheck the filename and its path under Manual/Images.
Duplicate anchorGive each section marker and explicit anchor a unique ID.
Missing link targetCheck the destination document and anchor, particularly after a rename.
Font resolution or packaging errorCheck that the requested font is available and that the reported font format is supported.
Source changed during exportFinish and save your edits, then export again.

Font search order

CFS checks the active game’s Fonts directory first, then the app-data Fonts directory, then OS fonts. A same-named font in an earlier location takes priority.

Keep the last good export

Exports are built in a staging folder before publication. Failures before installation preserve the previous published output.

PDF

The PDF tab has its own dimensions, margins and output controls. Its current renderer differs from Web. Review both typography and layout before treating a PDF as print-ready; the manual’s Web appearance is not a promise of identical PDF output.
